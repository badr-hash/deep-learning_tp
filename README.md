# Travaux pratiques — réseaux récurrents

Notebooks pédagogiques consacrés aux réseaux de neurones récurrents et à la modélisation de séquences.

## Notebooks

- [Comparaison RNN simple et Deep RNN](Deep_RNN_Comparaison.ipynb) : architectures à une ou plusieurs couches, implémentation et comparaison expérimentale avec PyTorch.
- [Modèle de langage RNN](<TP_RNN_modele_de_langage%20(1).ipynb>) : travail pratique sur les réseaux récurrents appliqués au langage.

## Utilisation

Ouvrir les notebooks sur GitHub pour lire les cellules, ou dans Jupyter pour les exécuter. Suivre les instructions et dépendances indiquées dans chaque notebook. L’exécution et les résultats n’ont pas été vérifiés dans un environnement neuf ; il s’agit de travaux d’apprentissage et non de modèles prêts à déployer.
